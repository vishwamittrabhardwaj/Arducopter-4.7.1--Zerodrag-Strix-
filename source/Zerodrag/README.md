# ZeroDrag Strix Board Definition

This directory contains the ZeroDrag Strix FCU hardware definition used to build the community ArduCopter 4.7.1 firmware.

## Build Information

- Flight stack: ArduCopter
- ArduPilot version: 4.7.1
- Target hardware: ZeroDrag Strix FCU
- Board definition: `hwdef.dat`

The firmware was built using the official ArduPilot 4.7.1 source together with the ZeroDrag Strix hardware definition contained in this directory.

The resulting firmware was flashed to a ZeroDrag Strix FCU and basic operation was verified.

## Source

The underlying ArduPilot source code is available from the official ArduPilot project.

This `hwdef.dat` contains the ZeroDrag-specific hardware configuration used for the build.

## Status

This is a community build and is not an official firmware release from ZeroDrag or ArduPilot.

Hardware compatibility should be verified by the user before operating an aircraft.
